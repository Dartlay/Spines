# 📚 Spines

### Мобильное приложение для чтения книг

---

## 📖 О проекте

**Spines** — это современное мобильное приложение для чтения книг, разработанное в рамках дипломной работы. Приложение предлагает удобный интерфейс для чтения, организации личной библиотеки и взаимодействия с книгами.

---

## ✨ Возможности

| | Функционал | Описание |
|:-:|:---|:---|
| 📖 | **Чтение книг** | Поддержка TXT и EPUB форматов с настройкой шрифта |
| 📚 | **Личная полка** | Создайте свою коллекцию книг с отслеживанием прогресса |
| ❤️ | **Избранное** | Сохраняйте понравившиеся книги в отдельный список |
| 🔍 | **Умный поиск** | Поиск по названию, автору, жанрам и году |
| ⭐ | **Отзывы и оценки** | Делитесь мнением о прочитанных книгах |
| 🌐 | **Мультиязычность** | Поддержка русского и английского языков |
| 🎨 | **Современный дизайн** | Приятный интерфейс с анимациями |
| 🔐 | **Авторизация** | Безопасный вход через Firebase |

---

## 🛠 Технологии

### Frontend
- **Flutter** — кроссплатформенная разработка
- **Dart** — язык программирования
- **Bloc** — управление состоянием
- **GoRouter** — навигация

### Backend
- **Firebase Authentication** — аутентификация пользователей
- **SharedPreferences** — локальное хранение данных
- **epubx** — парсинг EPUB файлов

### Архитектура
- **Clean Architecture** — разделение на слои
- **Repository Pattern** — работа с данными
- **Dependency Injection** — управление зависимостями

---

## 📱 Основные экраны

### 1. Главный экран
- Приветствие с учетом времени суток
- Горизонтальные списки книг (новинки, рекомендуемые, популярные)
- Быстрый доступ к фильтрам

### 2. Детали книги
- Подробная информация о книге
- Кнопки добавления на полку и в избранное
- Отзывы других читателей

### 3. Читалка
- Плавное перелистывание страниц
- Настройка размера шрифта
- Автосохранение прогресса чтения

### 4. Моя полка
- Загрузка своих книг (TXT, EPUB)
- Отображение прогресса чтения
- Редактирование информации о книгах

### 5. Избранное
- Список понравившихся книг
- Быстрое удаление из избранного

### 6. Фильтры
- Поиск по названию и автору
- Фильтр по жанрам, году, рейтингу
- Сортировка результатов

### 7. Профиль
- Смена языка (русский/английский)
- Выход из аккаунта
